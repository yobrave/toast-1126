# The Funniest Toaster Error Message

The error message a kitchen toaster would show its owner, in 120 characters or fewer. Run the builder:

```sh
python main.py
```

It checks `entry.txt` against the 120-character gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
